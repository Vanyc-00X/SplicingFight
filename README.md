# SplicingFight

Windows-десктоп приложение для SMM каратэ-клуба: локальная обработка видео боёв, трекинг спортсмена, AI-кандидаты лучших моментов и простой монтаж под Reels / YouTube.

## Возможности (MVP)

1. **Проект** — импорт MP4/MOV/MKV, proxy 720p, метаданные боя.
2. **Моменты** — клик по спортсмену, YOLO-трекинг, smart-crop 9:16 / 16:9, AI-хайлайты (движение + pose + звук зала).
3. **Монтаж + экспорт** — текст, лого, музыка, таймлайн, очередь рендера, пресеты Reels/YouTube.
4. **Библиотека** — локальный индекс клипов, открытие файла, повторный экспорт.

## Требования

- Windows 10/11
- Python 3.11+
- FFmpeg (через пакет `imageio-ffmpeg`, системный `ffmpeg` тоже подойдёт)
- GPU NVIDIA желателен (есть CPU-fallback)

## Установка

```bash
cd D:\Dowland\SplicingFight
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

При первом трекинге скачается `yolov8n.pt`, при AI-моментах — `yolov8n-pose.pt`.

## Запуск

```bash
python main.py
```

## Данные

Локально в `%LOCALAPPDATA%\SplicingFight\`:

- `splicingfight.db` — проекты, моменты, очередь, библиотека
- `projects/` — proxy и tracking.json
- `library/` — экспортированные ролики
- `cache/` — аудио и превью хайлайтов

## Типовой сценарий SMM

1. Вкладка **Media** → **+ Создать проект** → выбрать медиапапку (видео и фото в Media Pool).
2. Двойной клик по ролику для превью → **Назначить исходником**.
3. **Cut / Моменты** → клик по спортсмену → трекинг → AI → принять клипы.
4. **Edit / Экспорт** → лого/музыка → экспорт Reels / YouTube.
5. **Deliver / Библиотека** → готовые файлы для публикации.

## Примечание

AI предлагает **кандидаты** моментов, а не судейскую разметку ippon/waza-ari. Ручная правка границ и принятие клипов — обязательный шаг.
